2. Dual Field Model

2.1 External Aspect: Quantity Field and Structure Field

$$Q : \Omega \times \mathbb{R}^+ \to \mathbb{R}^m, \quad S : \Omega \times \mathbb{R}^+ \to \mathbb{R}^k$$

2.2 Internal Aspect: Generative Operator

Behind the external mapping $\Phi$, there exists a non-local, hierarchical generative operator $G$:

$$\Phi(Q)(x,t) = \int_{\Omega} K\big(Q(y,t), \nabla Q(y,t), \Sigma(t)\big) \, W(x,y) \, dy$$

Where:

$K$: Local generative kernel (includes effects of external singularities)

$W(x,y)$: Non-local weight (determines the spatial extent of the structure field)

⚠️ Notice: Internal structure (kernel decomposition, hierarchical generation) is non-disclosed.

3. Singularity Structure

3.1 External Aspect: Singularity Set

$$\Sigma(t) = \{ x \in \Omega \mid S(x,t) \text{ is discontinuous or non-smooth} \}$$

3.2 Internal Aspect: Singularity Generative Kernel

Singularities are generated by gradients, vorticity, and non-local structures of the quantity field:

$$\Sigma(t) = \left\{ x \;\middle\vert{}\; \int_{\Omega} H\big(Q(y,t), \nabla Q(y,t)\big) \, \delta(x-y) \, dy > \theta \right\}$$

Where:

$H$: Singularity generative kernel (does not include non-disclosed internal structures)

$\theta$: External threshold
